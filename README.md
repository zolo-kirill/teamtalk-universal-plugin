# TeamTalk Universal Plugin

Универсальный плагин для TeamTalk 5: музыка и другое аудио в голосовом канале по ссылкам и поиску, плюс оповещатель о входе/выходе пользователей в Telegram. Аудио передаётся как голос (`TT_InsertAudioBlock`), звуковые устройства не требуются.

## Возможности

- Все команды в TeamTalk — со слэшем: `/п`, `/sub`, `/h`. Личное сообщение боту без слэша пересылается главному админу и назначенным админам в Telegram (с возможностью ответить). Сообщения в канал (включая индикаторы набора «typing») в Telegram не пересылаются — чат не засоряется
- Поиск и проигрывание: `/п <запрос>`, `/пи <запрос>` — YouTube, список до 10 результатов
- Справка: `/h` / `/помощь` — список команд; в статусе бота подсказка «отправь /h»
- Кто на сервере: `/online` в Telegram-боте — список пользователей, сейчас подключённых к серверу. Каждый — кнопка: нажми — карточка с действиями: написать личное сообщение прямо в TeamTalk (текст вводится в Telegram, уходит пользователю в личку на сервере; отмена — любая команда со слэшем), кикнуть или забанить (для обычных пользователей, админов трогать нельзя). Кнопка «Назад» возвращает к списку
- Плейлисты: вставь ссылку на плейлист YouTube или Яндекс.Музыки (например «Мне нравится») — весь плейлист встаёт в очередь, не только первые 100 треков
- Список плейлиста: `/пл <страница>` — полный список постранично (20 треков на странице)
- Автопереход по списку: после окончания трека бот сам играет следующий (бесшумно, без спама в личку)
- Переключение: `/n` / `/b` — следующий/предыдущий из списка поиска или плейлиста
- Пауза/продолжить: `/пи` (нажать ещё раз — пауза)
- Стоп: `/с` / `/стоп`; скип: `/скип` / `/дальше`
- Громкость: `/v <1-100>` — плавно, без резких скачков
- Перемотка: `/sf <секунды>` — вперёд, `/sf -5` — назад
- Автоисправление ссылок: если ID видео в ссылке с неверным регистром (YouTube различает регистр) — бот сам находит канонический и играет
- Прямые ссылки Яндекс.Музыки на трек (`music.yandex.ru/album/<id>/track/<id>`) — играет через YM API (yt-dlp такие ссылки не тянет)
- Выбор сервиса: `/sv yt` / `/sv ym` (YouTube / Яндекс.Музыка)
- Локальные файлы: `/lf <путь>` — проиграть файл с диска
- Загрузить играющий трек в канал: `/dl` — бот загружает текущий трек файлом на сервер TeamTalk в свой канал (файл появляется в списке файлов канала, его можно скачать в клиенте). Радио и треки без локального файла загрузить нельзя
- Озвучка названий: `/vo` — вкл/выкл голосовое объявление названия перед каждым треком (синтез через Google Translate TTS)
- Смена ника: `/cn <ник>` (сохраняется между рестартами)
- Смена статусного сообщения: `/cs <текст>` — что написано под ником бота (пусто — очистить; сохраняется между рестартами)
- Радио: `/радио` — список станций, `/радио <номер>` — запустить, `/радио <текст>` — поиск по названию
- Избранное: `/f` — список сохранённого, `/f +` — добавить текущий трек/радио, `/f + <ссылка>` — добавить ссылку, `/f <номер>` — сыграть, `/f - <номер>` — удалить (сохраняется между рестартами)
- Телеграм-реле: в бота можно кидать аудио/видео/голосовые — транслируются в канал. Команды из Telegram работают так же, как в TeamTalk (`/п`, `/n`, `/v`, `/f`, `/радио`, …): отвечает в этот же чат. Меню команд бота в Telegram (`/help`, `/п`, …) настраивается автоматически. Управлять ботом может только владелец — `telegram_relay.owner_user_id`
- Объявление запросов: команда-«запрос» из Telegram объявляется в канале TeamTalk — «Кирилл запросил: радио ремикс FM». Род глагола («запросил/запросила») склоняется по полу автора из его профиля TeamTalk, если автор подписан на уведомления (`/sub`). Служебные команды (`/online`, `/help`, `/admins`, `/subs`, `/kick`, `/net`, …) и свободный текст не объявляются
- Двухсторонние реплики: если пользователь в TeamTalk напишет боту личное сообщение (не команду), оно пересылается админам в Telegram (в notify-чат `telegram_relay.notify_chat_id` и лички админов). Ответь на это сообщение в Telegram — и бот отправит твой ответ тому пользователю в личку. Ответить можно в течение часа после пересылки (хранятся в `replies.json`)
- Подписка на уведомления: `/sub` в TeamTalk (личное сообщение боту) — бот присылает индивидуальную ссылку `t.me/<бот>?start=sub_<token>`; открой её в Telegram — и будешь получать входы/выходы на сервере себе в личку, включая собственный вход и выход (уведомление приходит и о себе). Отписаться — командой `/unsub` в боте (работает по тексту, в меню команд её нет — управление в списке подписчиков `/subs`). Ссылки хранятся в `subs.json` (живут 24 часа), подписки переживают рестарт
- Подписка на музыку в Telegram: `/sub mus` в TeamTalk (личное сообщение боту) — бот присылает ссылку `t.me/<музыкальный_бот>?start=sub_mus_<token>`; открой её в Telegram — и каждый играющий трек будет присылаться тебе файлом в личку. Требуется отдельный музыкальный бот (`TG_MUSIC_TOKEN`)
- Администраторы: музыку заказывает любой, управление ботом — только админам. В TeamTalk админ определяется по правам на сервере (`USERTYPE_ADMIN`). В Telegram админы — владелец из конфига (`owner_user_id`) плюс назначенные. Список админов: `/admins`. Назначение/снятие админа и отписка подписчика — только в списке подписчиков `/subs` (кнопки «Назначить админом»/«Убрать из админов» у владельца, «Отписать от уведомлений»): команд `/admin`, `/unadmin`, `/delsub`, `/unsub` в меню бота нет (по тексту они работают). Назначенному админу бот присылает уведомление в личку Telegram. В списке подписчиков показывается имя человека из Telegram (first_name + last_name), не user ID. Владельца кнопками отписать или снять с админов нельзя — сервер передаётся правкой `owner_user_id` в конфиге. Не-админы админских команд не видят вовсе: в меню Telegram (`setMyCommands` по scope) и в справке `/help` им показываются только общие команды
- Кик/бан из Telegram: `/kick`, `/ban`, `/unban` — список онлайн-пользователей кнопками (админов и самого бота нет в списке). Бан кикает пользователя и банет его IP на сервере (не вернётся); разбан снимает IP-бан серверно; записи банов — в `bans.json`
- Сетевое сообщение: `/net <текст>` в Telegram — broadcast на весь сервер TeamTalk: сообщение видят все подключённые пользователи, в любом канале (в клиенте это «Send network message»). Требует у учётки бота привилегию broadcast
- Оповещатель: уведомления в Telegram о входе и выходе пользователей на сервере («присоединился/покинул сервер») — `telegram_relay.notify_chat_id`. Род склоняется по полу пользователя, заданному в его профиле TeamTalk: женский — «присоединилась/покинула», иначе — «присоединился/покинул». Для этого бот должен заходить под админской учёткой (иначе видит только свой канал); боты на этой же учётке в `telegram_relay.ignore_users` не анонсируются
- PulseAudio-вывод: если в конфиге задан `general.pulse_sink` (например `"ttbot"`), трек играет через PulseAudio — ffmpeg выводит в sink, бот захватывает его монитор. Так в канал можно транслировать любой звук машины

## Конфигурация

Все настройки в `config.json` (шаблон — `config_default.json`): данные TeamTalk-сервера (hostname, порты, логин, пароль, ник, канал), токен Яндекс.Музыки, пути к cookie-файлам, токен Telegram-бота, громкость, стартовые команды.

`config.json` лежит в папке бота и в git не попадает. Бот читает `config.json`, затем переменные окружения, затем значения по умолчанию.

Установщик `install.sh` при установке спрашивает Telegram-настройки и пишет их в `.secrets/.env` рядом с ботом: `TG_TOKEN` — токен бота-реле, `TG_OWNER_USER_ID` — твой Telegram ID (только он управляет ботом в Telegram), `TG_NOTIFY_CHAT_ID` — чат для уведомлений о входе/выходе пользователей. Аналогичные поля в `config.json` — `telegram_relay.token`, `telegram_relay.owner_user_id`, `telegram_relay.notify_chat_id`.

**Музыкальный бот.** `TG_MUSIC_TOKEN` (`telegram_relay.music_token`) — токен отдельного Telegram-бота для рассылки треков подписчикам (`/sub mus`). Поле по желанию: если его не задавать, музыка в Telegram не работает, а остальной функционал бота не меняется.

**YouTube-куки.** Полный экспорт кук (Netscape-формат) положи в `yt_cookies.txt` в папке бота и укажи путь в `services.yt.cookiefile_path`. Бот на каждый поиск/скачивание даёт yt-dlp свежую копию этого файла — мастер-файл не портится (yt-dlp иначе перезаписывает куки и вычищает авторизацию).

Дополнительные переменные окружения: `YT_JS_RUNTIME` — путь к deno (по умолчанию `~/.local/bin/deno`); `YT_PO_TOKEN_EXTRACTOR` — extractor-args для po-токенов, пустое значение отключает (нужно, если нет bgutil-сервера).

**PulseAudio-вывод.** `general.pulse_sink` — имя PulseAudio-sink, через который бот играет звук (например `"ttbot"` при null-sink). Требуются ffmpeg с pulse-выходом и `parec`. Пустое значение — прежний путь: декод прямо в PCM, звуковые устройства не нужны. Нужен также работающий PulseAudio-сервер (на headless-машине — null sink, см. `module-null-sink`).

После изменения конфига перезапусти бота командой `rs` в TeamTalk.

## Требования

- Ubuntu/Debian (x86_64), Python 3.8+, ffmpeg
- TeamTalk 5 SDK для Ubuntu 22.04 x86_64 (папка `sdk/tt5sdk*` с `libTeamTalk5.so`) — входит в репозиторий
- Доступ к TeamTalk-серверу и права бота в канале: `USERRIGHT_TRANSMIT_VOICE`

## Установка

### 1. Клонируй репозиторий

```bash
git clone https://github.com/zolo-kirill/teamtalk-universal-plugin.git
cd teamtalk-universal-plugin
```

### 2. Проверь TeamTalk SDK

SDK входит в репозиторий, отдельно качать ничего не нужно:

```bash
ls sdk/tt5sdk*/Library/TeamTalk_DLL/libTeamTalk5.so
```

### 3. Установи системные пакеты

```bash
sudo apt-get update
sudo apt-get install -y ffmpeg python3 python3-pip python3-venv
```

### 4. Автоустановщик

```bash
bash install.sh
```

Установщик создаёт `.venv` с yt-dlp и yandex-music, проверяет SDK, создаёт шаблон `.secrets/.env`, ставит пользовательский systemd-сервис `teamtalk-universal-plugin` с автозапуском. Бот работает под твоим пользователем (не root), sudo нужен только для установки системных пакетов.

Полная ручная установка без скрипта — в разделе «Ручная установка (без скрипта)» ниже.

### 5. Настрой `config.json`

Заполни данные сервера, токены и пути к кукам — см. «Конфигурация». Значения можно также задать переменными окружения: они используются как фолбэк, если поле в конфиге пустое.

### 6. Запуск

```bash
bash run.sh
```

Или, если ставил через `install.sh`, — сервис уже работает и поднимется сам после перезагрузки:

```bash
systemctl --user status teamtalk-universal-plugin    # статус
journalctl --user -u teamtalk-universal-plugin -f    # логи
```

## Ручная установка (без скрипта)

Не хочешь пользоваться `install.sh` — поставь всё руками. Каждый шаг ниже самодостаточен, с нуля.

### 1. Системные пакеты

```bash
sudo apt-get update
sudo apt-get install -y git ffmpeg python3 python3-pip python3-venv
```

### 2. Клонирование

```bash
git clone https://github.com/zolo-kirill/teamtalk-universal-plugin.git
cd teamtalk-universal-plugin
```

### 3. Проверка SDK

```bash
ls sdk/tt5sdk*/Library/TeamTalk_DLL/libTeamTalk5.so
```

SDK входит в репозиторий. Если файла нет — репозиторий склонирован не полностью, бот не запустится.

### 4. Окружение Python

```bash
python3 -m venv .venv
.venv/bin/pip install --upgrade pip yt-dlp yandex-music
```

### 5. Секреты

Создай папку секретов рядом с репозиторием (на уровень выше) и файл `.env`:

```bash
mkdir -p ../.secrets
```

Файл `../.secrets/.env`:

```ini
TEAMTALK_HOST=адрес_сервера
TEAMTALK_TCP_PORT=10333
TEAMTALK_UDP_PORT=10333
TEAMTALK_USERNAME=логин
TEAMTALK_PASSWORD=пароль
TEAMTALK_NICKNAME=MusicBot
TEAMTALK_CHANNEL=
TG_TOKEN=токен_телеграм_бота
TG_OWNER_USER_ID=твой_telegram_id
TG_NOTIFY_CHAT_ID=id_чата_для_уведомлений
TG_MUSIC_TOKEN=токен_музыкального_бота (по желанию)
```

Разбор переменных:

- `TEAMTALK_HOST`, `TEAMTALK_TCP_PORT`, `TEAMTALK_UDP_PORT`, `TEAMTALK_USERNAME`, `TEAMTALK_PASSWORD` — адрес сервера, порты и учётка для входа.
- `TEAMTALK_NICKNAME` — как бота видно в канале.
- `TEAMTALK_CHANNEL` — название канала; пусто — корневой канал.
- `TG_TOKEN` — токен Telegram-бота для реле (взять у @BotFather). Пусто — реле выключено.
- `TG_OWNER_USER_ID` — твой Telegram ID: только этот пользователь управляет ботом в Telegram. Узнать свой ID можно у @userinfobot.
- `TG_NOTIFY_CHAT_ID` — куда слать уведомления о входе/выходе пользователей (пусто — выключено).
- `TG_MUSIC_TOKEN` — токен отдельного Telegram-бота для рассылки треков подписчикам `/sub mus` (пусто — музыка в Telegram выключена). Создать бота можно у @BotFather.

Токен Яндекс.Музыки положи одной строкой в `../.secrets/ym_token.txt`. Куки YouTube (Netscape-формат) — в `../.secrets/cookies.txt` и укажи путь к ним в `config.json` → `services.yt.cookiefile_path`.

### 6. Конфиг

```bash
cp config_default.json config.json
```

Бот читает `config.json` в первую очередь, затем переменные окружения из `.secrets/.env`, затем значения по умолчанию. Минимально достаточно переменных из `.env`; `config.json` нужен, если хочешь менять громкость, подключаемые сервисы или пути к кукам.

### 7. Запуск

```bash
bash run.sh
```

`run.sh` сам подхватит SDK, venv и `.secrets/.env`. Первый запуск в фоне:

```bash
nohup bash run.sh > bot.log 2>&1 &
```

### 8. Автозапуск через systemd

```bash
mkdir -p ~/.config/systemd/user
```

Файл `~/.config/systemd/user/teamtalk-universal-plugin.service`:

```ini
[Unit]
Description=TeamTalk Universal Plugin
After=network.target

[Service]
Type=simple
WorkingDirectory=/путь/к/teamtalk-universal-plugin
ExecStart=/bin/bash /путь/к/teamtalk-universal-plugin/run.sh
Restart=always
RestartSec=10

[Install]
WantedBy=default.target
```

Запусти и включи автозапуск:

```bash
systemctl --user daemon-reload
systemctl --user enable --now teamtalk-universal-plugin
loginctl enable-linger $(id -un)   # сервис переживёт перезагрузку
```

Логи: `journalctl --user -u teamtalk-universal-plugin -f`.

## Файлы

- `bot.py` — основной бот (ctypes-биндинги TeamTalk)
- `config.json`, `config_default.json` — конфигурация (рабочий файл и шаблон)
- `radio/` — плейлисты радиостанций (m3u)
- `run.sh` — обёртка запуска (SDK env, секреты, venv)
- `install.sh` — автоустановщик
- `teamtalk-universal-plugin.service` — systemd-юнит
