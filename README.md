# teamtalk-universal-plugin

Бот для сервера TeamTalk 5. Играет музыку и другое аудио в голосовом канале, управляется командами из TeamTalk и Telegram, присылает уведомления о входах и выходах, защищает сервер от автоматизированных подключений и обрабатывает заявки на учётные записи.

Звук передаётся в канал голосовым потоком, поэтому звуковая карта не нужна: достаточно ffmpeg.

## Что умеет

- Поиск и воспроизведение по запросу: YouTube, Яндекс-Музыка, RuTube; ссылки и плейлисты целиком.
- Радиостанции, избранное, «Моя волна» Яндекс-Музыки, очередь и автопродолжение после перезапуска.
- Управление из Telegram: пульт на кнопках, команды, уведомления, список онлайн, кик и бан.
- Голосовые сообщения и аудиофайлы из Telegram сразу играют в канале.
- Список онлайн, кик, бан и разбан из Telegram; бот не ходит по ссылкам на внутренние адреса сервера.
- Регистратор: заявка на учётную запись, подтверждение администратором, готовый файл `.tt`.

## Требования

Ubuntu или Debian, Python 3.10 и новее, ffmpeg, systemd. Бот работает под обычным пользователем, запускать установщик от root нельзя.

Windows 10 и новее — установщик `install.bat`, подробности в разделе «Windows». Права администратора не нужны ни там, ни там.

## Установка

```bash
git clone https://github.com/zolo-kirill/teamtalk-universal-plugin
cd teamtalk-universal-plugin
bash install.sh
```

Установщик открывает меню: 1 — установить всё, 2 — только зависимости, 3 — только конфигуратор, 4 — только служба, 5 — шаблон `ttplugin@имя` для нескольких серверов на одной машине, 6 — удалить. Всё подряд без меню: `bash install.sh all`.

**Что спросит конфигуратор**

1. Адрес сервера TeamTalk, TCP- и UDP-порт, логин и пароль бота, ник, канал (пусто — корневой). Адрес, логин и пароль обязательны.
2. Telegram, можно пропустить: токен бота для команд и уведомлений, ваш Telegram ID (он же владелец), ID чата для уведомлений, второй токен для музыкального бота.
3. Токен Яндекс-Музыки и пути к `cookies.txt` YouTube и `rutube_cookies.txt`, можно пропустить.
4. Подтверждение введённых данных.

**Что делает установщик**

1. Ставит пакеты: ffmpeg, python3 с pip и venv, curl, wget, unzip, git, p7zip.
2. Создаёт `.venv` и ставит `requests`, `yt-dlp`, `yandex-music`; предлагает поставить Deno, он нужен yt-dlp для YouTube.
3. Скачивает TeamTalk SDK с bearware.dk и проверяет, что библиотека загружается и импортируется. Если сборка не подходит по версии glibc, берёт следующую, в крайнем случае SDK из репозитория.
4. Проверяет доступ к `api.telegram.org`. Если он закрыт, спрашивает ключ `vless://`, `vmess://`, `trojan://` или готовый `socks5://` и `http://`, ставит Xray, проверяет конфигурацию и пишет прокси в `.secrets/.env`.
5. Создаёт `.secrets/.env` с правами 600 — он лежит рядом с папкой бота, а не внутри неё.
6. Ставит пользовательскую службу `tt-plugin`, включает автозапуск и запускает бота.

## После установки

```bash
systemctl --user status tt-plugin       # состояние
journalctl --user -u tt-plugin -f       # журнал
systemctl --user restart tt-plugin      # перезапуск
loginctl enable-linger $(id -un)        # служба живёт после перезагрузки без входа
```

Перезапуск из чата командой `rs`. Ручной запуск без службы: `bash run.sh`, проверка путей: `bash run.sh --show`.

## Windows

Тот же бот, только ставится из проводника: без systemd, без root и без прав администратора.

1. Скачайте репозиторий кнопкой `Code` → `Download ZIP` и распакуйте, например в `C:\teamtalk-universal-plugin`.
2. Запустите `install.bat` — откроется окно установки.

В окне два десятка полей: адрес сервера и пароль бота, данные Telegram, пути к cookies, три галочки — поставить зависимости, запускать при входе в Windows, запустить сразу после установки. Значения из прошлой установки подставляются сами из `.secrets\.env`. Вкладка «Установка» показывает журнал по ходу дела: видно, что ставится и где остановилось.

Установщик проверит Python, ffmpeg и Deno и при отсутствии поставит их через `winget`, создаст `.venv`, поставит зависимости и скачает TeamTalk SDK для 64-битной Windows с bearware.dk.

Тот же установщик без окна: `install.bat -Console`. Совсем без вопросов, только программы и SDK: `install.bat -Console -Unattended`.

**Как запускать**

- `run.bat` — бот в отдельном окне, весь вывод перед глазами. Окно можно свернуть, закрывать нельзя.
- Фоном — без окна, вывод пишется в `logs\bot.log`. Запись в автозапуск добавляется в раздел текущего пользователя, поэтому права администратора не нужны.

**Служебные команды**

```
.venv\Scripts\python windows\setup.py status    состояние
.venv\Scripts\python windows\setup.py stop      остановить
.venv\Scripts\python windows\setup.py start     запустить в фоне
.venv\Scripts\python windows\setup.py config    изменить настройки
.venv\Scripts\python windows\setup.py sdk       перекачать TeamTalk SDK
```

**Чем отличается от Linux**

- Автозапуск срабатывает при входе в Windows: до входа в систему бот не работает, службой он не становится.
- Прокси для Telegram сам не настраивается. Если `api.telegram.org` недоступен, допишите в `.secrets\.env` строку `TG_PROXY=socks5://127.0.0.1:1080` и держите прокси запущенным отдельно.
- Команды `rs` и `cookies` работают как обычно: бот выходит, а запускающая программа поднимает его заново.
- Обновление: сделайте `git pull` или распакуйте новую версию поверх. Установщик заново не нужен, если не менялись зависимости.

## Команды

Команды одинаковые в TeamTalk и Telegram. В TeamTalk бот принимает их личным сообщением, в Telegram — обычным сообщением; косая черта необязательна. Регистр букв не важен.

### Воспроизведение

- `play <запрос>`, `p` — поиск и воспроизведение; без запроса пауза или продолжение.
- `pause`, `resume` — пауза и продолжение.
- `stop`, `s` — стоп с очисткой очереди; `skip` — следующий трек.
- `n`, `next` — следующий; `b`, `back`, `prev` — предыдущий.
- `queue`, `q` — очередь; `playlist <страница>` — очередь постранично.
- `u <ссылка>`, `link`, `url` — играть по ссылке. Ссылка, отправленная боту в личку или в канал, тоже играет.
- `radio`, `r` — список станций; `radio <номер>` — запустить станцию.
- `f`, `fav` — избранное: `f +` добавить текущий, `f + <ссылка>` добавить ссылку, `f <номер>` играть, `f - <номер>` удалить.
- `mow`, `волна` — «Моя волна» Яндекс-Музыки.

### Звук и источники

- `v <1–100>`, `volume` — громкость; без числа бот назовёт текущую.
- `sf <секунды>` — перемотка вперёд, `sb <секунды>` — назад.
- `sv yt` — искать на YouTube, `sv ym` — на Яндекс-Музыке.
- `status`, `now` — что играет сейчас.
- `lf <путь>` — файл с диска бота; `dl` — отправить текущий трек файлом в канал.
- `sub` — подписка на уведомления о входах и выходах.
- `cookies` — принять файл куки YouTube, сохранить и перезапуститься.

### Оформление

- `cm` — ответы бота в канал или в личные сообщения.
- `cn <ник>` — сменить ник; `cs <текст>` — статус.
- `channel <путь>` — перейти в канал.
- `sc` — сохранить ник, сервис и громкость в конфигурацию, чтобы остались после перезапуска.

### Служебное

- `help`, `h` — справка из четырёх частей.
- `rs` — перезапуск бота.

### Только в Telegram

- `start` — для владельца приветствие, для остальных активация подписки по ссылке `/start sub_…`.
- `panel`, `пульт` — пульт на кнопках: назад, пауза, дальше, тише, громче, стоп, что играет, кто онлайн.
- `online`, `who` — кто на сервере, у каждого кнопки «написать», «исключить», «бан».
- `kick <ник>` — исключить; `ban <ник>` — заблокировать с подтверждением.
- `unban <IP или ник>` — разблокировать; без аргумента покажет список блокировок с кнопками.
- `net <текст>` — сетевое сообщение всем на сервере.
- `admins` — список администраторов; `admins + <ID>` добавить, `admins - <ID>` убрать.
- `subs` — администраторы и подписки на кнопках.
- `unsub` — отписаться от уведомлений.
- `cancel` — отменить ожидающий ответ.

Служебные команды — `kick`, `ban`, `unban`, `net`, `admins`, `subs`, `panel` — доступны владельцу и администраторам. Остальным бот отвечает, что команда служебная.

## Обновление и удаление

```bash
cd teamtalk-universal-plugin
git pull
systemctl --user restart tt-plugin    # если служба уже стоит
```

Полное удаление: `bash install.sh uninstall`.

На Windows то же самое делается кнопкой `Download ZIP` поверх старой папки и перезапуском бота; встроенной команды удаления нет — достаточно закрыть бота, выключить автозапуск и удалить папку.

## Полезное

- Конфигурация: рабочий файл `config.json` в папке бота в git не попадает, эталон — `config_default.json`. Токены и пароли лежат отдельно, в `.secrets/.env`.
- Куки YouTube в формате Netscape кладутся в `.secrets/cookies.txt`, путь задаётся при установке или командой `cookies`.
- RuTube: для подмены TLS-отпечатка нужен пакет `curl_cffi`, установщик ставит его вместе с остальными зависимостями. Если бот ставился раньше, добавьте вручную: `.venv/bin/pip install curl_cffi`.
- Один токен — один процесс. Несколько экземпляров бота с общим токеном получат от Telegram `409 Conflict`, и команды достанутся случайному серверу, поэтому каждому нужен свой бот.
- Звук слышат только те, кто в том же канале, что и бот.
