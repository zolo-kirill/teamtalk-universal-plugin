Программа: домашний туннель для universal plugin
==================================================

Назначение
Программа соединяет домашний компьютер с сервером бота. Через это
соединение бот выходит в интернет домашним подключением, на котором
YouTube доступен без ограничений.

Требования
Компьютер под управлением Windows, включённый и подключённый к
интернету. Данные для подключения (адрес сервера, логин, файл ключа)
выдаёт установщик setup.sh, который запускается на сервере бота.

Первичная настройка
1. Положить файл ключа (hometun.ppk) в папку программы.
2. Запустить start-tunnel.bat.
3. Ответить на вопросы: адрес сервера, порт, логин, код безопасности.
   Если значение в подсказке подходит, нажать Enter, не вводя новое.
4. Настройки сохраняются в файл config.txt. При следующих запусках
   программа их переспрашивать не будет.

Запуск
1. Запустить start-tunnel.bat.
2. При запросе Windows о доступе к сети выбрать «Разрешить доступ».
3. Сообщение «Подключено» означает, что соединение установлено.

Работа
Окно программы должно оставаться открытым, компьютер — включённым.
При обрыве связи программа переподключается автоматически.

Остановка
Закрыть окно программы. Повторный запуск — снова start-tunnel.bat.

Смена сервера
Удалить файл config.txt и запустить программу заново либо
отредактировать config.txt.

Неисправности
Обратиться к администратору, который настраивал сервер.
