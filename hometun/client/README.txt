Программа: домашний туннель для universal plugin
==================================================

Что это такое.
Эта программа связывает домашний компьютер с сервером бота.
Благодаря ей бот может выходить в интернет через твой домашний
интернет, где YouTube работает свободно.

Что нужно.
Компьютер на Windows, включённый и подключённый к домашнему интернету.
Данные для подключения: адрес сервера, логин и файл ключа. Их выдаёт
серверный скрипт установки (setup.sh) тому, кто настраивает сервер бота.

Как настроить при первом запуске.
1. Положи файл ключа (hometun.ppk) в эту же папку, если его ещё нет.
2. Запусти start-tunnel.bat (встань на файл и нажми Enter).
3. Программа задаст несколько вопросов: адрес сервера, порт, логин,
   код безопасности. Отвечай и нажимай Enter после каждого ответа.
   Если в подсказке уже есть значение в скобках и оно подходит -
   просто нажимай Enter.
4. Настройки сохранятся в файл config.txt. При следующих запусках
   программа вопросов задавать не будет.

Как запускать.
1. Запусти start-tunnel.bat.
2. Если Windows спросит разрешение для сети или брандмауэра -
   выбери "Разрешить доступ".
3. Через несколько секунд программа сообщит: "Подключено! Теперь
   YouTube в боте работает." Это значит, что всё готово.

Что делать дальше.
Оставь окно программы открытым. Не закрывай его, пока нужен YouTube.
Компьютер тоже должен оставаться включённым. Если связь оборвётся,
программа подключится снова сама.

Как остановить.
Просто закрой окно программы. Чтобы снова включить - запусти
start-tunnel.bat ещё раз.

Как сменить сервер.
Удали файл config.txt и запусти программу снова - она заново
спросит данные. Либо отредактируй config.txt обычным блокнотом.

Если что-то пошло не так.
Напиши тому, кто настраивал тебе сервер. Он поможет.
